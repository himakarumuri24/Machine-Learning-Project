# 🚗 Electric Vehicle Range Prediction Using Machine Learning

## 📖 Overview

This project predicts the driving range (km) of electric vehicles using Machine Learning. The model is trained on EV specifications such as battery capacity, top speed, torque, charging power, efficiency, vehicle dimensions, and other technical features.

The objective is to estimate how far an electric vehicle can travel on a single charge based on its specifications.

---

## 🎯 Objective

To develop a Machine Learning model capable of accurately predicting the driving range of electric vehicles using technical and performance-related features.

---

## 🚀 Features

- Data Loading from ZIP file
- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis (EDA)
- Feature Selection
- Train-Test Split
- Random Forest Regression Model
- Feature Importance Analysis
- Model Evaluation
- Actual vs Predicted Visualization

---

## 📊 Dataset Features

- Battery Capacity
- Top Speed
- Number of Cells
- Torque
- Efficiency
- Acceleration
- Fast Charging Power
- Towing Capacity
- Cargo Volume
- Number of Seats
- Vehicle Length
- Vehicle Width
- Vehicle Height

Target Variable:

- Range (km)
